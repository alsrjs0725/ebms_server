# 개인정보 처리방침

EBMS(이하 "서비스")는 로그인과 곡 다운로드에 필요한 최소한의 정보만 처리합니다. 이메일, 실명, 비밀번호, 전화번호는 저장하지 않습니다.

## 1. 처리하는 항목과 보유기간

| 항목 | 목적 | 보유기간 |
| --- | --- | --- |
| 로그인 서비스(Google, Discord)의 계정 ID, 닉네임 | 회원 식별과 로그인 | 탈퇴할 때까지 |
| 로그인 세션 | 로그인 유지 | 만료·로그아웃 후 30일 |
| 다운로드 기록과 월별 사용량 | 다운로드 한도 적용 | 재차감 면제 기간 끝까지 / 12개월 |
| 접속 IP, 접속 시각, 요청 경로 | 장애 대응과 부정 이용 방지 | 서버 30일, 중계 서버 최대 6주 |

위 정보는 서비스 제공(계약 이행)에 필요하므로 별도 동의 없이 처리합니다(개인정보 보호법 제15조 제1항 제4호). 보유기간이 지나면 복구할 수 없게 지웁니다. 관리자의 조회·변경 기록과 서버 운영 로그는 보안을 위해 최대 1년 보관합니다.

## 2. 제공과 위탁

제3자에게 제공하지 않습니다. 다운로드 중계 서버 호스팅과 그 접속 기록 보관을 Oracle Cloud Infrastructure에 맡깁니다.

중계 서버가 국외에 있어 다음과 같이 개인정보를 국외로 이전합니다(개인정보 보호법 제28조의8).

| 항목 | 내용 |
| --- | --- |
| 이전받는 자 | Oracle Corporation (개인정보 문의: [문의 양식](https://www.oracle.com/legal/data-privacy-inquiry-form/), Global Data Protection Officer, 233 South Wacker Drive, 45th Floor, Chicago, IL 60606, USA) |
| 이전 국가 | 미국 |
| 이전 시기와 방법 | 서비스 이용 시 네트워크로 수시 전송 |
| 이전 항목 | 접속 IP, 접속 시각, 요청 경로, User-Agent |
| 목적과 보유기간 | 다운로드 중계와 접속 기록 보관, 최대 6주 |
| 거부 방법 | 서비스 제공에 필요하므로, 거부하려면 이용을 중단해야 합니다 |

## 3. 쿠키

웹 로그인 유지용 `ebms_session`(30일, 이용 시 연장)과 로그인 과정 보호용 `ebms_oauth`(10분)만 씁니다. 브라우저에서 거부할 수 있지만 그러면 웹 로그인을 할 수 없습니다.

## 4. 이용자의 권리

설정 페이지(/account)에서 내 정보를 확인하고, 로그인 수단 연결 해제와 계정 삭제(탈퇴)를 직접 할 수 있습니다. 탈퇴하면 회원 정보와 다운로드 기록을 바로 지웁니다. 그 밖의 열람·정정·처리정지 요청은 아래 연락처로 보내 주세요.

## 5. 안전조치

모든 통신은 https로 암호화하고, 세션 토큰은 해시값만 저장하며, 관리 기능은 관리자만 쓸 수 있습니다.
