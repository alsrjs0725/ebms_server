# 개인정보 처리방침

[[운영자 이름]](이하 "운영자")은 EBMS 서비스(이하 "서비스")를 운영하면서 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 관련 고충을 원활하게 처리하기 위해 다음과 같이 개인정보 처리방침을 정해 공개합니다.

## 1. 처리하는 개인정보 항목과 목적

서비스는 회원 가입과 로그인, 곡 다운로드 제공에 필요한 최소한의 정보만 처리합니다. 로그인 서비스의 이메일과 이름, 비밀번호, 전화번호, 주민등록번호와 민감정보는 저장하지 않습니다.

| 항목 | 목적 | 수집 방법 |
| --- | --- | --- |
| 로그인 서비스(Google, Discord)의 계정 ID | 회원 식별, 로그인, 계정 연결 | 로그인할 때 해당 서비스에서 받음 |
| 닉네임 | 서비스 화면 표시 | 가입할 때 이용자가 직접 입력 |
| 가입·로그인·마지막 사용 시각 | 세션 유지와 만료 처리 | 이용 중 자동 생성 |
| 곡별 다운로드 기록, 월별 다운로드 사용량, 남은 티켓 수 | 다운로드 한도 적용 | 이용 중 자동 생성 |
| 접속 IP 주소, 접속 시각, 요청 경로 | 장애 대응, 부정 이용 방지, 보안 | 서버 접속 기록(로그) |

## 2. 처리 근거

위 항목은 이용자가 요청한 서비스(로그인과 곡 다운로드)를 제공하는 계약을 이행하는 데 필요하므로, 「개인정보 보호법」 제15조 제1항 제4호에 따라 별도 동의 없이 처리합니다. 서비스는 동의를 근거로 처리하는 개인정보가 없습니다.

## 3. 보유기간과 파기

- 회원 정보(계정 ID, 닉네임): 회원 탈퇴(계정 삭제) 시까지
- 로그인 세션: 만료되거나 로그아웃한 뒤 30일
- 곡별 다운로드 기록: 같은 곡을 다시 받아도 차감하지 않는 기간이 끝나면 바로
- 월별 다운로드 사용량: 이번 달을 포함해 12개월
- 서버 접속 기록: [[예) 3개월]]
- 서버 운영 로그(계정 ID가 남을 수 있음): 최대 1년

보유기간이 지나거나 처리 목적을 이루면 지체 없이 파기합니다. 전자 파일은 복구할 수 없는 방법으로 삭제합니다.

## 4. 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 법령에 특별한 규정이 있는 경우는 예외로 합니다.

## 7. 쿠키

서비스는 로그인 유지를 위해 다음 쿠키만 씁니다. 광고·분석 쿠키는 쓰지 않습니다.

| 쿠키 | 목적 | 보관 기간 |
| --- | --- | --- |
| ebms_session | 웹 로그인 유지 | 30일(이용할 때마다 연장) |
| ebms_oauth | 로그인 과정의 위조 요청 방지 | 10분 |

브라우저 설정에서 쿠키 저장을 거부할 수 있습니다. 다만 거부하면 웹 로그인을 할 수 없습니다.

## 8. 정보주체의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보 열람, 정정, 삭제, 처리정지를 요구할 수 있습니다.

- 설정 페이지(/account)에서 계정 정보, 로그인 수단, 로그인한 기기를 확인하고 연결 해제·로그아웃할 수 있습니다.
- 그 밖의 요구(계정 삭제 등)는 아래 개인정보 보호책임자에게 이메일로 요청하면 지체 없이(10일 이내) 처리합니다.

## 9. 안전성 확보 조치

- 모든 통신을 TLS(https)로 암호화합니다.
- 세션 토큰은 원문 대신 해시값만 저장합니다.
- 관리 기능은 관리자 계정만 접근할 수 있습니다.

## 10. 만 14세 미만 아동

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보임을 알게 되면 지체 없이 파기합니다.
