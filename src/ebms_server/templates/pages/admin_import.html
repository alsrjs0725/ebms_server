var/tmp 가져오기

서버의 var/tmp/에 있는 곡 폴더와 zip을 지금 등록합니다(서버 시작 시와 같음). 등록한 폴더와 zip은 지웁니다. 수 GB 이상이면 웹 업로드보다 zip을 내부망으로 서버의 var/tmp/에 복사(SMB, scp 등)한 뒤 누르는 편이 훨씬 빠릅니다. 복사 중에 누르지 않도록, 다른 이름으로 복사한 뒤 .zip으로 바꾸세요.
