zip 업로드

차트 파일({{ formats | join(", ") }})이 있는 폴더를 곡 하나로 등록합니다. zip 하나에 곡 여러 개가 있어도 되고, zip 최상위에 차트가 있으면 zip 이름을 곡 폴더명으로 씁니다. 같은 차트가 이미 있으면 기존 곡에 연결됩니다. 큰 파일도 조각으로 나눠 올리고, 등록은 서버에서 이어서 진행되므로 다 올린 뒤에는 페이지를 닫아도 됩니다.

var/tmp 가져오기

서버의 var/tmp/에 있는 곡 폴더와 zip을 지금 등록합니다(서버 시작 시와 같음). 등록한 폴더와 zip은 지웁니다. 수 GB 이상이면 웹 업로드보다 zip을 내부망으로 서버의 var/tmp/에 복사(SMB, scp 등)한 뒤 누르는 편이 훨씬 빠릅니다. 복사 중에 누르지 않도록, 다른 이름으로 복사한 뒤 .zip으로 바꾸세요.

"천천히"는 작은 단위로 나눠 등록하고 사이사이 쉬어서, 등록하는 동안에도 다운로드와 사이트 응답이 느려지지 않게 합니다(대신 두 배 이상 오래 걸림). 등록 중인 작업도 아래 목록에서 속도를 바꿀 수 있습니다.
